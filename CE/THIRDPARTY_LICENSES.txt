PopSNES (SHARP Brain PW-G5200 Windows CE port) - Third-party licenses
=====================================================================

This port bundles third-party code and data: the snes9x2002 emulation
core (including the ZSNES DSP-1 code it compiles in), the libretro API /
libretro-common headers, and bitmap glyph data
derived from the Shinonome and Galmuri font projects (CE/ce_shinonome16.h,
CE/ce_galmuri14.h, CE/ce_galmuri11.h) for the Japanese/English UI text.
This file collects their notices and should ship alongside the binary.

Quick summary:
  - The emulation core (section 1) is under the original Snes9x
    license, which is NON-COMMERCIAL / personal-use only. PopSNES as a
    whole is distributed on the same terms as upstream (the Snes9x
    non-commercial license): it must not be sold or bundled with
    anything sold, and must not be described as "free/open-source
    software" without that restriction stated.
  - The DSP-1 code in src/dsp1emu.c (section 1b), which src/dsp1.c
    compiles in with #include, is by the ZSNES Team under the GNU GPL,
    version 2 or later. Upstream carries it this way; this file does
    not claim that the upstream license terms are consistent with each
    other.
  - The libretro headers / libretro-common (section 2) are MIT.
  - The MSVC compat shim (section 3) is BSD-3-Clause and is bundled but
    not compiled by the Windows CE build.
  - The Shinonome bitmap font (section 4) is effectively Public Domain.
  - PopSNES's own code is MIT, and the menu mascot and the app icon
    are CC0 1.0 (section 5). The README screenshots are not covered by
    any license of this repository (section 5).
  - The Galmuri font (after section 5) is under the SIL Open Font
    License 1.1.
  - No game ROMs are included.

Galmuri font (Galmuri14, GalmuriMono11)
---------------------------------------
Upstream: https://github.com/quiple/galmuri
Version used: 2.40.4 (commit 71e1cac)
Copyright (c) 2019-2025 Lee Minseo (quiple@quiple.dev)
License: SIL Open Font License, Version 1.1 (full text below)

PopSNES embeds glyph data for its Japanese/English menu text. The default
build (make, CE_FONT=galmuri14) uses glyphs converted from Galmuri14;
the characters Galmuri14 does not have (Greek, Cyrillic and some math
symbols) are filled in from the Shinonome 16dot font described above.
